Engineering Highlights

System Architecture & Optimization

Handling 43M+ rows requires strict engineering rigor beyond simple script execution. Here are the core distributed architectural decisions implemented across the cluster:

Broadcast Joins & Partition Pruning

Eliminated costly network shuffle operations by broadcasting lookup dimension tables to worker executors. Configured dynamic partition pruning on release dates and genres, boosting PySpark execution speed by 3.8x.

PySpark • Memory Tuning

Idempotency & Data Quality

Enforced strict schema validation upon HDFS intake. Out-of-spec or null records are isolated into dead-letter quarantine paths, with partition-level atomic overwrites ensuring pipeline reruns never duplicate rows.

Schema Enforcement • Zero Duplication

Columnar Parquet Compression

Converted raw CSV data into columnar Parquet format using Snappy compression across HDFS DataNodes. Reduced physical storage from 5.6 GB to 1.8 GB (67% reduction) while accelerating downstream Spark SQL projection queries.

HDFS • Parquet • Snappy

Automated DAG Scheduling & SLAs

Production Airflow DAGs with exponential backoff retry policies, dependency sensors for upstream file arrivals, and automated webhook alerts for any task SLA breach, ensuring zero silent pipeline failures.

Airflow • Fault Recovery
